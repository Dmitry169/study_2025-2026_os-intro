# Введение

## Актуальность

Markdown с Pandoc — распространённый способ подготовки технической документации, независимый от конкретного текстового процессора.

## Цель работы

Научиться оформлять отчёты с помощью легковесного языка разметки Markdown.

## Задачи

- Сделать отчёт по предыдущей лабораторной работе в формате Markdown.
- Предоставить отчёт в 3 форматах: pdf, docx и md (в архиве, поскольку он должен содержать скриншоты, Makefile и т. д.).

## Объект и предмет исследования

Объект — текстовый документ в формате Markdown; предмет — его преобразование в pdf/docx средствами Pandoc.

## Методы исследования

Эмпирический метод: практическое выполнение заданий в виртуальной машине Fedora Linux с фиксацией результатов скриншотами и видеозаписью.

## Схема выполнения работы

Работа выполнялась по стандартной схеме курса: выполнение действия в виртуальной машине, фиксация скриншотом, занесение в отчёт, публикация в git-репозиторий отдельным релизом.

# Теоретическая часть

Markdown — лёгкий язык разметки, преобразуемый в другие форматы (pdf, docx, html) с помощью конвертера Pandoc. Для подготовки печатных документов с кириллицей используется движок xelatex совместно со шрифтом, поддерживающим кириллицу; pandoc-crossref добавляет нумерацию и перекрёстные ссылки на рисунки/таблицы.

Более подробно см. в [@robbins_book_bash_en].

# Материалы и методы

Используемое ПО и оборудование: хост-машина под управлением Windows, гипервизор VirtualBox, виртуальная машина с Fedora Linux (Sway), стандартные утилиты дистрибутива.

# Выполнение лабораторной работы

Скачиваем сборку `pandoc-crossref`, соответствующую установленной версии pandoc: `curl -LO https://github.com/lierdakil/pandoc-crossref/releases/download/v0.3.20/pandoc-crossref-Linux-X64.tar.xz`.

![Скачиваем сборку `pandoc-crossref`, соответствующую установленной версии pandoc: `curl -LO https://github.com/lierdakil/pandoc-crossref/releases/download/v0.3.20/pandoc-crossref-Linux-X64.tar.xz`](фото/1.png){width=70%}

Распаковываем архив: `tar -xf pandoc-crossref-Linux-X64.tar.xz`.

![Распаковываем архив: `tar -xf pandoc-crossref-Linux-X64.tar.xz`](фото/2.png){width=70%}

Переносим программу в `/usr/local/bin`, даём права на запуск и проверяем версию: `sudo mv pandoc-crossref /usr/local/bin/`, `sudo chmod 755 /usr/local/bin/pandoc-crossref`, `pandoc-crossref --version`.

![Переносим программу в `/usr/local/bin`, даём права на запуск и проверяем версию: `sudo mv pandoc-crossref /usr/local/bin/`, `sudo chmod 755 /usr/local/bin/pandoc-crossref`, `pandoc-crossref --version`](фото/3.png){width=70%}

Создаём рабочий каталог для отчёта с подпапкой для скриншотов: `mkdir -p ~/lab3-report/фото`.

![Создаём рабочий каталог для отчёта с подпапкой для скриншотов: `mkdir -p ~/lab3-report/фото`](фото/4.png){width=70%}

Копируем в него текст отчёта по лабораторной работе № 2: `cp ~/lab2-report/report.md ~/lab3-report/`.

![Копируем в него текст отчёта по лабораторной работе № 2: `cp ~/lab2-report/report.md ~/lab3-report/`](фото/5.png){width=70%}

Копируем скриншоты лабораторной работы № 2: `cp ~/lab2-report/фото/* ~/lab3-report/фото/`.

![Копируем скриншоты лабораторной работы № 2: `cp ~/lab2-report/фото/* ~/lab3-report/фото/`](фото/6.png){width=70%}

Создаём `Makefile` для автоматической сборки отчёта в форматы pdf и docx, указав движок `xelatex` со шрифтом `FreeSerif` для корректного отображения кириллицы и фильтр `pandoc-crossref`.

![Создаём `Makefile` для автоматической сборки отчёта в форматы pdf и docx, указав движок `xelatex` со шрифтом `FreeSerif` для корректного отображения кириллицы и фильтр `pandoc-crossref`](фото/7.png){width=70%}

Запускаем сборку: `make all`. Pandoc последовательно собирает `report.docx` и `report.pdf` из `report.md`.

![Запускаем сборку: `make all`. Pandoc последовательно собирает `report.docx` и `report.pdf` из `report.md`](фото/8.png){width=70%}

Упаковываем `report.md`, `report.pdf`, `report.docx`, `Makefile` и папку `фото` в архив и проверяем его содержимое: `zip -r lab3-report.zip report.md report.pdf report.docx Makefile фото`, `unzip -l lab3-report.zip`.

![Упаковываем `report.md`, `report.pdf`, `report.docx`, `Makefile` и папку `фото` в архив и проверяем его содержимое: `zip -r lab3-report.zip report.md report.pdf report.docx Makefile фото`, `unzip -l lab3-report.zip`](фото/9.png){width=70%}

# Результаты

В ходе выполнения работы получены следующие объективные результаты: Изучены основные элементы синтаксиса Markdown и освоена обработка Markdown-документов с помощью Pandoc. Установлен `pandoc-crossref` (вручную, поскольку в стандартном репозитории Fedora он отсутствует), написан `Makefile` для автоматической сборки отчёта сразу в двух форматах. На основе отчёта по лабораторной работе № 2 собраны `report.pdf` и `report.docx`, все материалы упакованы в единый архив вместе со скриншотами и Makefile.
